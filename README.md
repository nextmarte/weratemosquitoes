# Aquiles

**Auditable host-directed antiviral target triage for arboviruses — with an *independent* verifier.**

Built for **Built with Claude: Life Sciences** (Anthropic + Gladstone Institutes), Builder track.

---

## The problem

Aedes-borne arboviruses — dengue, Zika, chikungunya, yellow fever — have **no approved antiviral**.
Host-directed therapy (drugging the *human* proteins the virus depends on) is the leading strategy, and
Gladstone-style interactomics (Krogan's Dengue/Zika host–pathogen maps) and CRISPR screens yield hundreds
of candidate host factors. Turning that list into *"which targets are worth pursuing, are druggable, and
why did prior antivirals fail?"* is manual and takes days.

## What Aquiles does

For each candidate host-factor gene, an orchestrated pipeline:

1. **Specialist** (Claude Haiku) gathers cited evidence from **Open Targets, DGIdb, and Europe PMC** and
   makes concrete, checkable claims (druggability, known drugs, safety, prior evidence, role).
2. **Independent verifier** (Claude Sonnet) checks **every claim, in an isolated context, against the raw
   database record** — confirm / correct / unsupported. It never sees the rest of the reasoning, so its
   judgement is ground-truth-anchored, not the same model reviewing itself.
3. **Synthesis** produces a calibrated, auditable **go / watch / no-go dossier** with a mechanistic
   hypothesis, a suggested validation experiment, and the likely reason prior repurposing trials failed.

The numbers (druggability, evidence strength, confidence) are computed in Python from the verified
evidence, not invented by the model.

### The differentiator

The hottest critique of AI-for-science tools (incl. Anthropic's own Claude Science) is that *the reviewer
is the same model checking itself — not an independent source of truth.* Aquiles makes verification
**independent and anchored to external database records.** On the curated set:

> **The independent verifier caught 52 of 79 specialist claims (66%)** as unsupported or in need of
> correction against the raw record — claims a self-checking pipeline would have kept.

## Surfaces

- **Web app** (Next.js) — ranked target landscape, the verifier-impact chart, and per-target auditable
  dossiers with the verifier's corrections shown inline.
- **MCP server** — the same functions are exposed as MCP tools (`list_candidates`, `assess_target`,
  `prioritize_targets`), queryable in natural language from Claude Code / Claude Desktop.
- **REST API** — auto-generated by the Gradio backend; the web app consumes it server-side.

Backend (Gradio) gives REST **and** MCP from one set of typed Python functions.

## Run it

Prereqs: `uv`, Node 20+, `pnpm`, and an `ANTHROPIC_API_KEY` in `.env` (copy `.env.example`).

```bash
# 1. deps
uv sync

# 2. precompute the dossiers (writes web/public/dossiers.json; external fetches are disk-cached)
uv run python scripts/precompute.py

# 3. the validated number (verifier ON vs OFF ablation)
uv run python scripts/eval.py

# 4. backend — REST + MCP on :7860
uv run python app.py                     # prints the MCP endpoint URL on startup

# 5. web app — on :3000 (calls the backend server-side)
cd web && pnpm install && pnpm build && pnpm start
```

Assess a single gene from the CLI:

```bash
uv run python -m aquiles.pipeline --gene VCP     # one dossier
uv run python -m aquiles.pipeline --all          # rank the whole set
```

### Use it from Claude (MCP)

```bash
# Claude Code (Linux) — copy the exact URL app.py prints (…/gradio_api/mcp/)
claude mcp add --transport http aquiles http://localhost:7860/gradio_api/mcp/
```

Then ask Claude: *"Use aquiles to assess the dengue host factor STT3A"* or *"prioritize the arbovirus
host-factor targets and explain the top one."*

### Deploy (server + Cloudflare)

Run the backend (`:7860`) and the web app (`:3000`) on the server; the web app reaches the backend at
`localhost:7860` (override with `GRADIO_URL`). Point a Cloudflare Tunnel at the web app:

```bash
cloudflared tunnel --url http://localhost:3000
```

## Architecture

```
data/host_factors.json + failed_trials.json     curated candidates + trial-failure corpus
        │
src/aquiles/clients.py     async Open Targets / DGIdb / Europe PMC clients (disk-cached)
src/aquiles/agents.py      specialist · independent verifier · synthesis (Claude, structured output)
src/aquiles/pipeline.py    orchestration, grounded scoring, deterministic fallback
        │
app.py (Gradio)  ──►  REST  ──►  web/ (Next.js dashboard + /api/assess proxy)
                 └──►  MCP   ──►  Claude Code / Desktop
```

## Honesty & safety

- The defensible claim is **independent, auditable verification** — not "the AI decides better than a
  scientist." Human-in-the-loop throughout; not a diagnosis or treatment recommendation.
- Every claim is source-linked; a claim only counts as evidence if the verifier confirms it against the
  raw record. Claims a safety classifier declined to assess are marked **unassessed** and excluded from
  the metric.
- Evidence: Open Targets, DGIdb, Europe PMC (all public, no key). Candidate provenance: Marceau *et al.*
  Nature 2016; Zhang *et al.* Cell Reports 2016; Shah *et al.* Cell 2018 (Krogan); Barrows *et al.* 2019.
- ⚠️ The `ANTHROPIC_API_KEY` was pasted during the build — **rotate it after the hackathon**.
